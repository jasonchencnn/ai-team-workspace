# ADR-0004：外部模型执行路由（含 R3）

- 状态：Accepted
- 提案日期：2026-09-24
- 接受日期：2026-09-24；Human 明确回复“批准 ADR-0004”
- 适用候选范围：Wave 2 尚未开始的节点；已完成或仍在 `REVIEW` 的旧实现不追溯改写执行模型
- 不变项：技术栈、领域/协议冻结规格、节点依赖、G0～G9、零新增费用上限；平台门禁自 2026-09-28 起按 ADR-0005 执行

> 本 ADR 的模型路由及独立审核要求继续有效；下文涉及 ADR-0003 双环境放行的历史条款，已由 [ADR-0005](0005-macos-first-quality-and-release-gates.md) 替代。

## 背景与冲突

Human 希望在 GPT 额度有限时，由 Codex 总控继续分工与终审；2026-09-24 进一步明确 Gemini-3.8-Flash 为主要开发模型，MiniMax-M3 暂不承担主开发，仅做边角辅助。这是 Human 的模型偏好，不是对模型能力的实测排名。`docs/development/DEVELOPMENT_NODES.md` 第 1 节和 `docs/development/QUALITY_GATES.md` 第 3 节仍为各风险级别指定了 GPT 执行模型，其中 migration、权限、进程、恢复与协议等 R3 节点要求 `gpt-5.6-sol`。仅在协作说明中改模型名字，会与冻结门禁冲突。

## 已接受的替代决策

1. 对尚未开始的 R1/R2 节点，Gemini-3.8-Flash 可在总控签发的单节点、互斥写集任务包内担任主要实现者。对 R3 节点也可担任主要实现者，但总控必须先拆出可审核的边界、指定失败反例，并以 `gpt-5.6-sol` 或更高模型逐差异复核安全、数据和协议语义。Gemini 负责阶段自验收，但不得用自验收替代独立复核、自行宣布正式 `DONE` 或扩充冻结语义。
2. MiniMax-M3 仅承担边角辅助：资料整理、fixture、机械性测试或互斥文件的低风险文档修改；不担任 Wave 2 节点主实现者，也不替代 R3 独立审核。其任务同样需要总控指定 `DEV-*`、文件归属和验收命令。
3. Gemini 参与某节点实现后，该节点必须由其他审核者独立复核。R3 仍保留冻结要求的独立反例审核、至少一种失败注入和 Sol 总控终审。原 ADR-0003 双环境证据独立审核的历史要求，自 ADR-0005 起适用于 Mac 单环境证据；总控逐项核验输入哈希、全 refs 历史扫描及工具来源。
4. 每个任务包包含难度理由、精确写集、冻结规格、成功/失败验收、定向命令、回退和停止条件。数据库 migration 与 Adapter 链分别单写者串行；已发布 migration 不修改。根 manifest/lockfile、跨节点整合与最终状态由总控串行处理。
5. 完整门禁不降级：依赖先 `DONE`，节点专属审核与 G0～G9、当前最终输入的 macOS ARM64 21 项门禁、全 refs 历史秘密扫描、证据包独立终审全部通过后才可 `DONE`；平台范围按 ADR-0005。任何证据缺口保持 `REVIEW/BLOCKED`。
6. 若模型输出无法证明冻结语义、出现 S0/S1、文件越界或不稳定测试，总控立即停止该派工并由 Sol 接手修复/复核；不得为了省额度降低门禁。

## 代价、替代与复审触发

- 收益：让 Gemini 承担主要实现，减少 Sol 的实现 token，把 GPT 额度集中于边界判断、负向审查和终审。
- 代价：外部模型能力、上下文保真和实际文件访问没有在本仓库得到验证；更多 Markdown 交接与集成成本，R3 错漏仍需 Sol 严格兜底。
- 回退方案：若触发下列复审条件，暂停新的 Gemini R3 派工，改由冻结节点表和质量门禁指定的 GPT 执行模型接手；保留已有实现与证据供复核，不清理用户改动。
- 复审触发：首个外部 R3 节点失败、证据质量不足、写集冲突、规格变更或成本/访问条件变化。出现上述情况即回到 Sol 执行要求，暂停新 R3 派工。

## Human 决策记录

- [x] 接受：允许 Gemini 主力开发、MiniMax 边角辅助的上述路由，后续总控按本 ADR 更新任务包和审核记录。
- [ ] 不接受。

本 ADR 只改变尚未开始节点的执行模型路由，不追溯改变已交付节点的实际模型，也不自动将 `REVIEW` 改为 `DONE`。Gemini 对工作期间的测试和阶段自验收负责；自验收记录不替代独立复核、节点正式 `DONE` 或总控的最终验收。
